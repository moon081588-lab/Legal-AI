# 앱 스토어 출시 가이드

현재 Legal-AI는 **웹 앱(PWA)** 입니다. 앱 스토어에 올리려면 네이티브 앱 껍데기가 필요합니다.
이 문서는 (0) 지금 당장 가능한 방법 → (1) 준비물 → (2) Capacitor로 앱 만들기 → (3) 심사 통과 전략 →
(4) 제출 절차 순서로 안내합니다.

---

## 0. 먼저: 앱 스토어가 정말 필요한가요?

**지금 당장, 무료로, 심사 없이 "앱처럼" 쓰게 하는 방법이 이미 준비되어 있습니다.** Legal-AI는 PWA로
만들어져 있어서, 배포만 하면 이용자가 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

| | PWA (홈 화면 추가) | App Store | Google Play |
|---|---|---|---|
| 비용 | 0원 | **연 $99** | 최초 $25 |
| 심사 | 없음 | 있음 (1~3일, 반려 가능) | 있음 (비교적 관대) |
| 업데이트 | 즉시 | 재심사 필요 | 재심사 필요 |
| 오프라인 | ✅ (이미 지원) | ✅ | ✅ |
| 검색 노출 | 웹 검색 | 앱 스토어 검색 | 앱 스토어 검색 |
| 이 프로젝트에 필요한 작업 | **없음** | Mac + Xcode + Capacitor | Capacitor 또는 TWA |

> **권고.** PoC 단계에서는 PWA로 먼저 공개해 실제 이용자 반응을 보고, 이후 "앱 스토어에서 찾을 수
> 있어야 한다"는 요구가 확인되면 그때 네이티브 앱을 만드는 순서를 권합니다. 앱 스토어 등록의 가장
> 큰 가치는 기능이 아니라 **발견 가능성과 신뢰감**입니다.

이용자에게는 이렇게 안내하면 됩니다:
- **iPhone**: Safari로 접속 → 공유 버튼 → "홈 화면에 추가"
- **Android**: Chrome으로 접속 → 메뉴 → "홈 화면에 추가" 또는 자동 설치 배너

## 1. 준비물 (App Store)

- **Mac** (필수 — Xcode는 macOS에서만 동작합니다)
- **Xcode** (App Store에서 무료 설치, 약 10GB)
- **Apple Developer Program 멤버십** — 연 $99, 가입 승인에 1~2일
  - 개인(Individual) 등록이면 실명이 개발자명으로 노출됩니다.
  - 단체명으로 내려면 법인/사업자등록번호와 D-U-N-S 번호가 필요합니다(발급 2주 내외).
- **배포된 웹 서비스** — [docs/deploy.md](deploy.md)를 먼저 완료하세요.
- **개인정보 처리방침 URL** — 이미 준비되어 있습니다: `https://<도메인>/privacy`
- **지원(문의) URL** — GitHub 저장소 주소로 갈음할 수 있습니다.

## 2. Capacitor로 네이티브 앱 만들기

[Capacitor](https://capacitorjs.com)는 웹 앱을 네이티브 앱으로 감싸 주는 도구입니다.

```bash
cd frontend
npm install @capacitor/core @capacitor/ios @capacitor/app @capacitor/share @capacitor/filesystem
npm install -D @capacitor/cli
npx cap init "Legal-AI" "kr.legalai.app" --web-dir=out
```

`frontend/capacitor.config.ts`를 다음과 같이 설정합니다. 서버 URL을 지정하면 배포된 웹 앱을 그대로
띄우면서도 네이티브 기능을 함께 쓸 수 있습니다.

```ts
import type { CapacitorConfig } from "@capacitor/cli";

const config: CapacitorConfig = {
  appId: "kr.legalai.app",
  appName: "Legal-AI",
  webDir: "out",
  server: {
    url: "https://<배포된-프론트-도메인>",
    cleartext: false,
  },
  ios: { contentInset: "always" },
};

export default config;
```

```bash
npx cap add ios
npx cap sync ios
npx cap open ios      # Xcode가 열립니다
```

Xcode에서 할 일:
1. **Signing & Capabilities** → Team을 본인 계정으로 선택
2. **Deployment Info** → iPhone/iPad 지원 여부 선택
3. 앱 아이콘 등록 (1024×1024 PNG 필요 — `frontend/public/icon.svg`를 변환)
4. 실제 기기 또는 시뮬레이터에서 실행해 동작 확인

## 3. 심사 통과 전략 (중요)

이 앱이 반려될 수 있는 지점과 대응입니다. **미리 대비하지 않으면 거의 확실히 반려됩니다.**

### 3.1 가장 큰 위험 — Guideline 4.2 "최소 기능"

애플은 **웹사이트를 그대로 감싸기만 한 앱을 반려**합니다. 대응 방법:

- 네이티브 기능을 실제로 사용하세요. 이 앱에 자연스러운 것들:
  - **증거 사진 촬영** (Camera) — 증거 일지에 바로 촬영해 첨부
  - **파일 저장/공유** (Filesystem, Share) — 상담 준비 요약서·증거 일지 내보내기
  - **기한 알림** (Local Notifications) — CCTV 30일, 고소 기한 등 로컬 푸시 ← 매우 자연스럽고 심사에도 유리
  - **생체 인증 잠금** (Face ID) — 증거 일지 보호. 피해자 앱에 설득력 있는 기능
- 앱 전용 오프라인 동작을 강조하세요(이미 구현되어 있음).

> **권고:** 최소한 **로컬 알림 + 생체 인증 잠금** 두 가지는 네이티브로 구현한 뒤 제출하세요.
> 두 기능 모두 이 앱의 목적(기한 놓치지 않기, 기록 보호)에 정확히 부합해 심사 논리도 명확합니다.

### 3.2 Guideline 5.1.1 — 개인정보

- App Store Connect의 **App Privacy(개인정보 라벨)** 를 작성해야 합니다.
- Legal-AI는 유리합니다: 계정 없음, 추적 없음. 다음과 같이 신고하면 됩니다.
  - Data Not Collected — 대부분 항목
  - "User Content(사용자 콘텐츠)" — 👎 피드백 시 질문 문장이 저장되므로 **"제품 개인화가 아닌 앱 기능"** 목적으로 신고하고, **추적에는 사용하지 않음**으로 표시
- 개인정보 처리방침 URL: `https://<도메인>/privacy` (이미 준비됨)

### 3.3 법률 서비스 관련

- 앱 설명과 앱 내부에 **"법률 자문이 아님"** 문구가 명확해야 합니다(이미 앱에 상시 노출).
- 변호사 자격을 사칭하거나 오인하게 하는 표현을 쓰지 마세요. 앱 이름·부제에 "변호사"를 넣지 않는 것을 권합니다.
- 심사 노트(App Review Notes)에 다음을 적어 두면 오해를 줄일 수 있습니다:
  > 본 앱은 대한민국 공공 법령 데이터(법제처 국가법령정보 API)를 기반으로 법령 정보를 안내하는
  > 무료 공익 서비스입니다. 법률 자문을 제공하지 않으며, 모든 답변에 AI 생성물임과 전문가 상담
  > 안내가 표시됩니다. 계정·결제·추적이 없습니다.

### 3.4 민감한 주제 (범죄 피해·자살예방 안내)

- 위기 상황에서 상담 전화를 안내하는 기능은 **감점 요소가 아니라 가점 요소**입니다. 다만 연령 등급
  설정 시 "잦은/심한 성적 또는 노골적 콘텐츠" 등에 해당하지 않도록 정확히 답하세요.
- 예상 연령 등급: **17+** (성폭력·범죄 피해 관련 정보 포함). 보수적으로 설정하는 편이 안전합니다.

### 3.5 심사 계정

- 로그인이 없으므로 심사용 계정은 불필요합니다. Review Notes에 "로그인 없이 모든 기능 사용 가능"이라고 적어 주세요.

## 4. 제출 절차

1. **App Store Connect**(appstoreconnect.apple.com) → 나의 앱 → **+ → 새로운 앱**
   - 플랫폼: iOS / 이름: `Legal-AI` (중복 시 예: `Legal-AI 생활법령 도우미`)
   - 기본 언어: 한국어 / 번들 ID: `kr.legalai.app` / SKU: 아무 문자열
2. **앱 정보** 입력
   - 부제(30자): 예) `범죄 피해자를 위한 법령 안내`
   - 카테고리: **참고(Reference)** 또는 유틸리티. (법률 카테고리는 없습니다)
   - 개인정보 처리방침 URL: `https://<도메인>/privacy`
3. **스크린샷** (필수)
   - 6.7인치(iPhone 15 Pro Max 등) 최소 3장, 6.5인치 최소 3장
   - 추천 화면: ① 질문–답변 + 근거 조문, ② 무료 지원 확인 결과, ③ 증거 체크리스트, ④ 절차 안내
4. **설명문** — 아래 초안을 참고하세요.
5. **Xcode → Product → Archive → Distribute App → App Store Connect** 업로드
6. App Store Connect에서 빌드 선택 → 연령 등급·수출 규정(암호화: 표준 암호화만 사용 → 보통 "아니요") 답변 → **심사 제출**
7. 심사 기간: 보통 24~48시간. 반려되면 사유가 명시되며, 수정 후 재제출은 무료입니다.

## 5. Google Play (더 쉬운 경로)

안드로이드는 **TWA(Trusted Web Activity)** 로 PWA를 거의 그대로 올릴 수 있고, 심사도 상대적으로
관대합니다. Mac이 필요 없습니다.

```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest https://<도메인>/manifest.webmanifest
bubblewrap build          # app-release-signed.apk / .aab 생성
```

Google Play Console($25, 1회)에 업로드하면 됩니다. 개인 개발자 계정은 최근 **비공개 테스트(12명, 14일)**
요건이 있을 수 있으니 콘솔 안내를 확인하세요.

## 6. 출시 후

- 앱 스토어 심사는 **업데이트마다** 필요합니다. 법령이 바뀌었을 때 즉시 반영하려면 Capacitor의
  `server.url` 방식(웹을 그대로 로드)이 유리합니다 — 콘텐츠는 재심사 없이 갱신됩니다.
- 크래시와 리뷰를 주기적으로 확인하고, 리뷰에 남은 법률 질문에는 답하지 말고 상담 창구를 안내하세요.
- 앱 스토어 등록 자체가 신뢰의 신호가 되므로, 등록 후에는 범죄피해자지원센터·법률구조공단 등에
  협력을 제안해 볼 만합니다.
