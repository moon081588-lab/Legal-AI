# 법률 전문가 검토 요청서

Legal-AI는 범죄 피해자 등 일반인에게 법령 정보를 안내하는 무료 오픈소스 서비스입니다.
서비스 공개 전, 아래 항목에 대한 법률 전문가(변호사·법학자)의 검토를 요청드립니다.
검토 의견은 GitHub 이슈 또는 moon081588@gmail.com 으로 보내 주시면 감사하겠습니다.

## 1. 검토가 필요한 콘텐츠

**증거확보 가이드 (`data/guides/evidence.jsonl`, 10개 항목)** — 특히:

- 가이드 3: 대화·통화 녹음의 적법 범위 설명이 통신비밀보호법 및 대법원 2001도3106 판결 취지에 부합하는지
- 가이드 5: CCTV 열람 청구(개인정보 보호법 제35조)와 제3자 촬영 영상의 한계 설명이 정확한지
- 가이드 7: 증거보전 청구(형사소송법 제184조) 설명과 2026. 6. 시행 개정 내용(피해자 열람·등사)의 반영이 정확한지
- 가이드 9: 위법수집증거 관련 판례(2007도3061, 2008도3990) 요지 설명이 정확한지

**서식 (`templates/`)**: CCTV 보존요청서, 고소장 기본 서식이 실무상 적절한지, "이용자가 직접 기입하는 자동화 서식" 범주에 해당하는지.

**샘플 조문 (`data/sample/*.jsonl`)**: 수작업 입력본이므로 현행 조문과의 불일치 지적 환영 (실서비스는 API 수집분 사용 예정).

**지원제도 안내 (`data/support.json`)** — 특히 검토가 필요합니다:

- 피해자 국선변호사 대상 범죄(성폭력·아동학대·장애인학대·인신매매·스토킹) 및 "소득 무관" 설명이 정확한지
- 법률구조공단 소송지원 기준(기준 중위소득 125% 이하)과 상담은 소득 무관이라는 구분이 정확한지
- 범죄피해구조금 요건·지급 범위(유족 28~48개월분, 장해 3~48개월분, 중상해 2~48개월분)와 2026. 3. 10. 시행 개정 내용(강력범죄 사망 시 24개월분 보장) 반영이 정확한지
- 구조금 신청 기한(안 날부터 3년, 발생일부터 10년) 안내가 정확한지
- 과실범죄(교통사고 등) 제외 설명이 적절한지

**기한 계산 (`data/deadlines.json`)**: 친고죄 6개월, 민사 소멸시효 3년/10년 등의 일반화된 안내가 오해를 낳지 않는지.

**연락처 (`data/centers.json`)**: 기관 대표번호와 지역 지부 번호의 최신성.

**용어 사전 (`data/glossary.json`)**: 20개 용어의 쉬운 말 정의가 법적으로 부정확하지 않은지.
